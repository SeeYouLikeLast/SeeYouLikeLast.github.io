滑动窗口

438. 找到字符串中所有字母异位词

滑动窗口+词频

我用固定长度滑动窗口。因为异位词只和字符频次有关，所以用 26 长度数组维护 p 和当前窗口的频次差。
右指针负责加入字符，左指针负责在窗口长度达到 p.length() 后移出字符。
只要窗口长度等于 p.length() 且 need 为 0，就说明当前窗口是 p 的异位词，记录 start。
时间 O(n)，空间 O(1)。

不用每次 Arrays.equals(countS, countP) 比较 26 个位置，而是用一个变量 need 记录窗口里还差多少个字符。

239. 滑动窗口最大值

我使用单调队列(Deque)维护当前窗口中可能成为最大值的元素下标。
队列从头到尾对应的值保持递减，所以队头就是当前窗口最大值。
遍历数组时，先移除滑出窗口的下标，再把队尾中小于等于当前值的元素移除，最后加入当前下标。当窗口大小达到 k 后，每次把队头对应的值加入答案。这样每个元素最多进队出队一次，时间复杂度是 O(n)。空间复杂度：O(k)

76. 最小覆盖子串

滑动窗口 + 字符频次统计。
右指针扩大窗口，直到窗口包含 t 的全部字符；然后移动左指针缩小窗口，寻找当前右边界下的最短合法窗口。
我使用滑动窗口维护 s 中的一个连续区间，并使用频次数组 need 记录当前窗口还需要每个字符多少个。右指针加入字符时，如果该字符原本仍然缺少，就将缺失字符总数 missing 减一，然后减少其需求量。当 missing 为零时，说明窗口已经覆盖 t，此时不断移动左指针缩小窗口并更新最短答案。左侧字符移出时恢复它的需求量，如果恢复后需求量大于零，说明移出了一个必要字符，窗口重新不合法。
左右指针最多各移动一次，因此时间复杂度为 O(m+n)，固定字符集下空间复杂度为 O(1)。

Hash + 堆排序

我先用哈希表统计每个元素出现的频率。
因为一个元素的频率最多不会超过数组长度 n，所以我可以用桶排序，把出现次数作为桶的下标。

快排

215. 数组中的第K个最大元素

Quick Select + Hoare 双路 partition
k 大元素，而且要求平均 O(n)，所以我使用 Quick Select。
第 k 大元素等价于升序数组中的第 n-k 个元素，因此我先计算目标下标 target = nums.length - k。
然后用 Hoare 双指针 partition。每次随机选择一个 pivot，把数组分成两部分：左边小于等于 pivot，右边大于等于 pivot。
partition 返回的是一个分界线 j，不是 pivot 的最终位置。所以不能判断 j == target，而是看 target 在分界线左边还是右边。
如果 j < target，说明目标在右半边，就令 left = j + 1；否则目标在左半边，就令 right = j。
每次只继续处理一边，所以平均时间复杂度是 O(n)，空间复杂度是 O(1)。
随机 pivot 可以降低退化概率

221. 最大正方形

这道题可以用动态规划。
定义 dp[i][j] 表示：以 matrix[i - 1][j - 1] 作为右下角时，能形成的最大正方形边长
如果当前位置是 '0'，那么它不可能作为全 1 正方形的右下角，dp[i][j] = 0。
如果当前位置是 '1'，那么它能形成的最大正方形边长，取决于它的左边、上边、左上角三个位置能形成的正方形边长。
所以状态转移是：
dp[i][j] = min(左边, 上边, 左上角) + 1。
遍历过程中记录最大边长，最后返回最大边长的平方。

152. 乘积最大子数组

这题是连续子数组乘积最大值。因为乘法里负数会改变大小关系，所以不能只维护最大乘积，还要维护最小乘积。
我定义 max 表示以当前位置结尾的最大乘积，min 表示以当前位置结尾的最小乘积。
遍历每个数 cur 时，新的最大乘积可能来自三种情况：cur 自己、cur 乘以前一个最大乘积、cur 乘以前一个最小乘积。
同理新的最小乘积也从这三种情况中取最小值。
每次更新 max 后，用它更新全局答案 ans。
最终返回 ans。时间复杂度 O(n)，空间复杂度 O(1)。

338. 比特位计数

我用动态规划。
对于数字 i，它右移一位得到 i / 2，也就是去掉二进制的最后一位。
所以 i 中 1 的个数，等于 i >> 1 中 1 的个数，再加上 i 的最后一位是否为 1。
因此状态转移方程是 ans[i] = ans[i >> 1] + (i & 1)。
整体只需要遍历一次，时间复杂度是 O(n)。

309. 买卖股票的最佳时机含冷冻期

动态规划 + 状态压缩
hold：手里持有股票
sold：今天刚卖出股票，明天进入冷冻期
rest：手里没有股票，并且今天没有卖出，可以正常买入

这题是股票系列的动态规划。因为有冷冻期，所以我把每天结束后的状态分成三类：持有股票 hold，今天刚卖出 sold，没有股票且可以买入的休息状态 rest。
如果今天持有股票，要么昨天就持有，要么今天从 rest 状态买入。
如果今天卖出，昨天必须持有股票。
如果今天休息，要么昨天已经休息，要么昨天刚卖出后今天进入冷冻状态。
最后答案一定是不持有股票，所以返回 sold 和 rest 的最大值。

时间复杂度：O(n)只遍历一次数组。
空间复杂度：O(1)

10. 正则表达式匹配

我用动态规划。dp[i][j] 表示 s 的前 i 个字符和 p 的前 j 个字符是否完全匹配。
如果当前模式字符不是 *，就看当前字符是否相等或者模式字符是否是 .，然后继承 dp[i-1][j-1]。
如果当前模式字符是 *，有两种情况：第一种是 * 匹配 0 个前面的字符，转移到 dp[i][j-2]；第二种是 * 匹配一个或多个前面的字符，如果(sc)当前字符能和 * 前面（pre）的字符匹配，就转移到 dp[i-1][j](避免多个)。最终返回 dp[m][n]。

时间复杂度：O(m * n) 空间复杂度：O(m * n)

72. 编辑距离

我使用动态规划，
定义 dp[i][j] 为将 word1 的前 i 个(i-1)字符转换成 word2 的前 j 个字符所需的最少操作数。
空字符串转换成长度为 j 的字符串需要插入 j 次，因此 dp[0][j]=j；
长度为 i 的字符串转换成空字符串需要删除 i 次，因此 dp[i][0]=i。
如果两个前缀的最后一个字符相同，不需要额外操作，状态继承左上角；如果不同，可以选择替换、删除或插入，分别对应左上角、上方和左边三个状态加一，取其中最小值。
时间复杂度为 O(mn)，由于每个状态只依赖上一行和当前行，可以使用滚动数组将空间优化到 O(min(m,n))。

96. 不同的二叉搜索树

我定义 dp(n) 表示使用 n 个有序且不同的节点能够构造出的二叉搜索树数量。
枚举第 i 个节点作为根节点，那么左子树有 i-1 个节点，右子树有 n-i 个节点。
左子树有 dp(i-1) 种结构，右子树有 dp(n-i) 种结构，两者可以任意组合，所以当前根节点贡献 dp(i-1) × dp(n-i) 种。
枚举所有根节点并求和，就得到卡特兰数递推。
标准 DP 的时间复杂度是 O(n²)、空间复杂度是 O(n)；进一步使用卡特兰数递推公式可以优化到 O(n) 时间和 O(1) 空间。

70. 爬楼梯

动态规划 + 滚动变量
我定义 dp[i] 为到达第 i 阶的方法数。到达第 i 阶的最后一步只有两种可能：从第 i-1 阶爬一步，或者从第 i-2 阶爬两步，因此状态转移为 dp[i] = dp[i-1] + dp[i-2]。初始状态是 dp[1]=1、dp[2]=2。由于当前状态只依赖前两个状态，所以不需要保存完整数组，
可以使用两个滚动变量将空间复杂度优化为 O(1)。时间复杂度为 O(n)。

区间DP

312. 戳气球

这题我会用区间 DP。直接考虑第一个戳哪个很难，因为戳破之后相邻关系会变化。
所以我反过来考虑：在一个区间中最后戳破哪个气球。
如果最后戳破的是 k，那么它左右两边的气球已经被戳完，此时它的左右邻居就是区间边界 i 和 j，收益固定为 arr[i] * arr[k] * arr[j]。
然后左右两个子区间互不影响，可以用 dp[i][k] + dp[k][j] 表示。

因此状态转移为：
dp[i][j] = max(dp[i][k] + arr[i] * arr[k] * arr[j] , dp[k][j])。
最终答案是 dp[0][n + 1]。

三层循环：区间长度 、len左边界 、i最后戳破位置 k，所以时间复杂度：O(n^3)
DP 数组大小是：O(n^2)所以空间复杂度：O(n^2)

5. 最长回文子串

我用 Manacher 算法。
首先把原字符串预处理成带 # 的形式，比如 "abba" 变成 "#a#b#b#a#"，这样可以统一奇数和偶数长度回文。
然后用数组 pArr[i] 表示以 i 为中心的回文半径，c 表示当前最右回文的中心，r 表示当前最右回文的右边界。
遍历每个位置时，如果 i 在 r 左边，就可以利用它关于 c 的对称点 2*c-i 的回文半径来初始化，但不能超过右边界，所以是 min(r-i, pArr[2*c-i])。
然后继续向两边扩散，更新最长回文和最右边界。最后根据最长回文中心和半径还原出原字符串中的答案。
时间复杂度是 O(n)，空间复杂度是 O(n)。

399. 除法求值

我会把每个变量看成并查集中的一个节点。普通并查集只能判断两个变量是否连通，但这题还要求除法值，所以我给每个节点维护一个权重 weight[x]，表示 x / parent[x]。

对于等式 a / b = value，我把 a 和 b 合并到同一个集合中，同时维护根节点之间的倍数关系。

查询 x / y 时，如果两个变量不存在，或者不属于同一个集合，返回 -1.0。如果属于同一个集合，那么答案就是 weight[x] / weight[y]。

由于使用了路径压缩，每次合并和查询都接近 O(1)，所以整体复杂度接近 O(E + Q)。

这题要求删除最少数量的无效括号，所以我先扫描字符串，计算最少需要删除多少个左括号和右括号，分别记为 lremove 和 rremove。 “）（”均不为0
然后用 DFS 回溯，每遇到一个括号，可以选择删除或者保留，但删除数量不能超过 lremove 和 rremove。

46. 全排列

我使用回溯。全排列就是每一层固定一个位置，通过交换枚举当前位置放哪个数，递归后再回溯恢复。

链表排序最适合用归并排序，因为链表不支持随机访问，快排不方便按下标划分，而归并排序只需要顺序遍历和指针操作。
我的做法是先用快慢指针找到链表中点，把链表断成左右两半。然后递归排序左右两半，最后合并两个有序链表。

如果 时间 O(n log n)，空间 O(1)。那就写 自底向上归并排序。—写法二

这道题如果要求 O(1) 额外空间，可以使用自底向上的归并排序。
先计算链表长度，然后从 size = 1 开始，每次把链表切成长度为 size 的两段进行合并。每一轮结束后，size 翻倍。

切链表时用 cut 函数把链表断开，合并时用 merge 函数合并两个有序链表。

142. 环形链表 II

这题我用 Floyd 快慢指针。
先让 slow 每次走一步，fast 每次走两步。如果链表无环，fast 会走到 null，返回 null。如果有环，fast 一定会在环内追上 slow。
当 slow 和 fast 第一次相遇后，让一个指针从 head 出发，另一个指针从相遇点出发。两个指针每次都走一步，它们再次相遇的位置就是入环节点。
原因是设 head 到入环点距离为 a，入环点到相遇点距离为 b，相遇点到入环点距离为 c。根据快指针走的距离是慢指针两倍，可以推出 a = c 加上若干个环长，所以两个指针同步走会在入环点相遇。

后序遍历 —- 当前节点的结果依赖左右子树的结果
这题是树形动态规划。对于每个节点，我维护两个状态：偷当前节点和不偷当前节点。

437. 路径总和 III

这题路径不一定从根开始，但必须向下，所以我使用前缀和加 DFS。

如果不能使用辅助栈，
我用一个栈存差值 diff = val - minVal，再用一个变量 minVal 记录当前最小值。
diff 小于 0 表示当前元素是新的最小值，pop 时可以通过 minVal - diff 恢复上一个最小值。
因为栈是后进先出，所以必须用 Stack 或 Deque，不能用 Queue。

146. LRU 缓存

这题要求 get 和 put 都是 O(1)，所以我用 HashMap 加双向链表 。

HashMap 负责通过 key 在 O(1) 时间找到对应节点。双向链表负责维护访问顺序，越靠近头部表示越新，越靠近尾部表示越旧。

get 的时候，如果 key 存在，就通过 map 找到节点，把它移动到头部，然后返回 value。

put 的时候，
如果 key 已经存在，就更新 value，并移动到头部。
如果 key 不存在，就新建节点插入头部，并放入 map。如果容量超了，就删除尾部前一个节点，也就是最久未使用的节点，同时从 map 中删除对应 key。

为了简化边界处理，我使用 dummy head 和 dummy tail。所有操作都是 O(1)。

169. 多数元素

这题因为题目保证多数元素一定存在，并且出现次数大于 n/2，所以我使用摩尔投票法。

我维护一个候选元素 candidate 和计数 count。遍历数组时，如果 count 为 0，就把当前元素作为候选人；如果当前元素等于候选人，count 加一，否则 count 减一。

这个过程相当于把多数元素和非多数元素两两抵消。由于多数元素数量超过一半，最终剩下的候选人一定是多数元素。
